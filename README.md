## 🚀 Project Overview

**chatroomApp** is a lightweight, web-based chat platform that allows users to join a chatroom, send messages, delete messages, and interact with a simple, clean frontend UI.  
This project focuses on implementing core chatroom functionality through frontend code while communicating with an existing backend using HTTP requests.


---

## 🔍 Features

- Join one of several chatroom pages  
- View all messages in the chatroom  
- Post new messages  
- Delete messages  
- REST API interaction for all operations  
- Lightweight and easy to extend
- user limiations until login

---

## 🧰 Tech Stack

- **Frontend:** JavaScript, React Native
- **Build Tool:** Vite  
- **API:** Express Js

## **1️⃣ Clone the Repository**

```bash
git clone https://github.com/JuanEulogio/AI_BadgerChat.git
cd AI_BadgerChat
```

2️⃣ Install Dependencies
```bash
npm install
```
or
```bash
yarn install
```

3️⃣ Start the Frontend
```bash
npm run dev
```

Vite will usually run at:
```bash
http://localhost:5173
```


🖥 Backend Setup (General Guidance)
This repository doesn't contain the hosted backend code.
Refer to the API_DOCUMENTATION.md to integrate your own version.
